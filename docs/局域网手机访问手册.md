# 智选无人超市 · 局域网手机访问手册

> 适用场景：演示、答辩、店内 Wi-Fi 测试。**手机无需安装 App**，用浏览器直接打开导购对话页。
> 电脑与手机连**同一个 Wi-Fi**即可。

---

## 0. 前置条件

- 电脑已启动后端 (`http://127.0.0.1:8000`) 与前端 (`http://127.0.0.1:5173`)
- 手机与电脑在**同一局域网**（同 Wi-Fi、同路由器）
- 后端绑定 `0.0.0.0` 而非 `127.0.0.1`，否则手机访问会被拒
- **Windows 防火墙放行 8000 / 5173**（右键 `enable-lan.bat` → 以管理员身份运行，一次性搞定）

## 0.5 最容易踩的坑（务必先看）

`ipconfig` 通常会列出多个 IP，**手机只能访问真实无线网卡上的 IP**。

| 网卡名 | 例子 IP | 手机能连吗？ |
|---|---|---|
| **WLAN / Wi-Fi / 以太网** | `192.168.1.x`、`10.50.112.x` | ✅ 能，手机用它 |
| VMware Network Adapter VMnet1 | `192.168.132.1` | ❌ 不能（VMware 虚拟网卡） |
| VMware Network Adapter VMnet8 | `192.168.86.1` | ❌ 不能 |
| Hyper-V / WSL 虚拟网卡 | `172.x.x.x` | ❌ 不能 |

> 简单判断：手机连同 Wi-Fi 后看手机自己拿到的 IP（设置 → WLAN → 当前网络 → IP），手机和电脑 IP 在**同一号段**（前三段相同，例如都是 `10.50.112.x`）才能互通。

## 1. 一键启动

**后端**（双击 `backend/start-backend.bat`）
```
D:\envs\supermarketenv\python.exe -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

**前端**（双击 `frontend/start-frontend.bat`）
```
npm run dev
```
Vite 已在 `vite.config.ts` 配置 `server.host: true`，自动监听 `0.0.0.0`。

终端最后会显示：
```
➜  Local:   http://localhost:5173/
➜  Network: http://192.168.x.x:5173/    ← 手机用这个
```

## 2. 查电脑局域网 IP

任选一种：
- PowerShell：`ipconfig | findstr IPv4`
- CMD：`ipconfig`
- Mac/Linux：`ifconfig | grep inet`

形如 `192.168.1.20` 的 IPv4 地址就是。

## 3. 手机访问

手机浏览器（Chrome / Safari / 微信内置浏览器）地址栏输：
```
http://192.168.x.x:5173/guide
```
即可看到完整导购对话页（含流式打字、商品卡片、库存三态标签）。

> 路径说明：
> - `/guide` — 导购对话页（手机端主力）
> - `/checkout` — 视觉结账台（建议在电脑/平板横屏访问）

## 4. 扫码进入指定商品

导购页顶部「扫一扫」按钮（📷 图标）：
- **Chrome / Edge / 安卓**：调用原生 `BarcodeDetector`，实时识别摄像头画面中的条码
- **Safari / 微信内置**：自动降级为「手动输入 SKU」对话框（如 `SKU002`）
- 扫到/输入后跳转到 `/guide?sku=SKU002`，导购 Agent 自动开场白介绍该商品并给出搭配建议

> 扫码权限：浏览器会请求摄像头授权，请选「允许」。

## 5. 常见问题（FAQ）

| 现象 | 原因 | 解决 |
|---|---|---|
| 手机访问提示「无法连接 / 网络拒绝访问」 | **Windows 防火墙拦了 5173/8000 入站** | **右键 `enable-lan.bat` → 以管理员身份运行**（一键放行） |
| 手机访问提示「无法连接」 | 后端还在 127.0.0.1 监听 | 重启后端，确保 `--host 0.0.0.0` |
| 手机访问提示「无法连接」 | **手机连的是访客网络 / 路由器开了 AP 隔离** | 换成主 Wi-Fi；或走 USB 桥接（`run-usb-bridge.bat`） |
| Vite 终端没显示 Network 地址 | `vite.config.ts` 未开 `host:true` | 已默认开启；若仍无，重启前端 |
| 手机扫码黑屏 | 浏览器无摄像头权限 | 地址栏左侧🔒图标 → 权限 → 摄像头 → 允许 |
| **夸克 / Edge / Safari 打开是空白页但 Chrome 正常** | 夸克/微信/部分 H5 内核的 WebView 不支持 `BarcodeDetector` | 没事，**手动输入 SKU**（如 `SKU002`）就能继续用 |
| 微信内置浏览器打开是「请在浏览器中打开」 | 公众号网页授权未配置 | 复制链接到系统浏览器；或改用 Chrome/Safari |
| 改 `.env` 后没生效 | uvicorn `--reload` 不监听 `.env` | 重启后端进程；用 `start-backend.bat` 双击启动 |
| **公司 / 校园网手机死活连不上电脑**（路由器隔离） | 安全策略禁止客户端互访 | 用 USB 数据线桥接：手机开 USB 调试 → 插电脑 → 双击 `run-usb-bridge.bat` → 手机访问 `http://127.0.0.1:5173/guide` |
| **手机浏览器提示「不安全 / 隐私设置错误 / 该网站未使用 HTTPS」** | 局域网 IP 是 HTTP 不带 S，部分手机端浏览器对内网 HTTP 默认禁止 | 用 Chrome 浏览器（最宽松）；或在夸克/Edge 设置里允许「加载不安全内容」 |

## 6. 端口占用时

```bash
# 查 8000 / 5173 占用进程 PID
netstat -ano | findstr ":8000 "
netstat -ano | findstr ":5173 "
# 杀掉
taskkill /PID <pid> /F
```

## 7. 生产环境提示

演示用局域网 H5 足够。若要发布到公网：
- **PWA**：加 manifest + service worker，用户「添加到主屏幕」获得类原生体验
- **微信 H5 / 小程序 web-view**：需 HTTPS 域名 + 备案公众号
- **原生 App**：用 RN/Flutter 复刻前端 `/guide` 页

本手册覆盖 A（局域网 H5）路径。其他路径可联系作者扩展。
