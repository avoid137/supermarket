> 这个差值衡量的是「上游查询改写」这一步的贡献。某个策略在改写后收益变小，说明它的强项（扛住长口语问句）与上游改写的作用重叠了。


### 为什么不能只看口径一

- 只看口径一，会得出「纯向量 92.3% 完胜现线上 84.6%，现有检索该换掉」的结论；但口径二显示两者的真实差距只有 +1.9pp。原因是向量擅长扛住长口语问句（「抽纸在哪个区？」），而线上模型传进来的本来就是「抽纸」这种短词——**向量这项优势被上游的查询改写提前吃掉了**。
- 字面策略受改写影响最大（+9.6pp），正说明它的瓶颈就是长句稀释 bigram；向量受影响最小（+1.9pp），两者是同一件事的两面。

### 拆开看：起作用的是「加向量」还是「换融合方式」？

第一轮的读法是「该换的是加权求和 → RRF」。补测两路 RRF（不含向量）后发现这个读法**不完整**——两路 RRF 只有 **82.7%**，比现线上（92.3%）还差 9.6pp。把两个变量拆开：

| | 两路（字面 + 属性） | 三路（+ 向量） |
| --- | --- | --- |
| **加权求和** | 92.3%（现线上） | 92.3% |
| **RRF** | 82.7% | **96.2%** |

- 加权求和下加向量路：**没有任何变化**（92.3% → 92.3%）。等权归一化平均会把向量的贡献稀释掉——余弦 top1 归一化后是 1.0、第二名 0.98，区分度被抹平。
- RRF 下加向量路：**+13.5pp**（82.7% → 96.2%）。向量单路 R@1 94.2% 是全场最高的排序质量，而 RRF 靠「排名投票」而不是分数求和，正好能把它用起来：向量认为对的商品，即使字面 / 属性路只排第 3~5 位，三路名次叠加后也能被顶到第一。
- 而 RRF 在两路时反而比加权求和差 **9.6pp**——所以「换融合方式」本身不是收益来源。

> **结论修正：「向量路」与「RRF 融合」必须配套。** 单加向量（放进加权求和里）**无效**，单换融合（两路 RRF）**有害**，两者一起才拿到 **96.2%**。这也解释了现线上 0.65 / 0.35 的配比为什么「看起来调得还行」——它是两路形态下的合理选择，但到不了三路 RRF 的水平。
- 另外 `rrf_strongvec` 与 `rrf_gated` 的全部指标完全相同：0.60 那条「强向量补召回」路径没有产生任何增量，是应该被删掉的复杂度。负结果留在这里，免得下次有人再想一遍。

## 向量阈值能不能自己当闸门？

纯向量的召回是全场最高（口径二 R@1 94.2%），却一条库外题都挡不住。所以真正要问的是：**把余弦阈值调高，能不能既保召回又保闸门？**

- 库内题的 top1 余弦：最低 **0.475**、中位 0.745、最高 0.930
- 库外题的 top1 余弦：`你们店有卖 iPhone 吗？` **0.399**、`有三文鱼刺身吗？` **0.530**、`我头疼，给我推荐一款止痛药。` **0.516**

| 余弦阈值 | 库内题通过（越高越好） | 库外题漏闸（越低越好） |
| --- | --- | --- |
| ≥ 0.30 | 52/52 | 3/3 |
| ≥ 0.35 | 52/52 | 3/3 |
| ≥ 0.40 | 52/52 | 2/3 |
| ≥ 0.45 | 52/52 | 2/3 |
| ≥ 0.50 | 51/52 | 2/3 |
| ≥ 0.55 | 50/52 | 0/3 |
| ≥ 0.60 | 49/52 | 0/3 |
| ≥ 0.65 | 42/52 | 0/3 |
| ≥ 0.70 | 34/52 | 0/3 |

> 库外题的最高余弦（**0.530**）高于库内题的最低余弦（**0.475**）——两条分布重叠，**不存在能把它们完美分开的阈值**。从扫描表看：要挡住全部库外题得把阈值提到 0.60，那时库内题只剩 49/52 能过。结论：余弦相似度里不包含「库里有 / 没有这件东西」这个信息，闸门只能由结构化信号（字面命中 / 属性命中）把关，向量只负责扩大召回。
